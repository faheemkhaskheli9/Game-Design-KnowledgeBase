# Game Design Knowledge Base

A reference on game design and gameplay for people and AI coding agents: what
makes games fun, core loops, difficulty and flow, player motivation, mechanics
and balance, randomness, combat, progression, rewards and loot, economies,
retention (without dark patterns), game feel, onboarding, level design,
narrative, multiplayer, prototyping and playtesting.

- `INDEX.md` - every topic with tags and use cases (generated).
- `scenarios/scenario-chooser.md` - start here with a symptom ("players quit early").
- `scenarios/design-review-checklist.md` - review a design or feature.
- `glossary.md` - terms, each linked to the topic that explains it.
- `AGENTS.md` - how agents consult and extend the base.

After adding or editing a topic: `python build_index.py`.
